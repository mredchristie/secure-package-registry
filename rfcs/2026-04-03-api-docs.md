## Summary

We have 3 main API surfaces:

- **External API**: Exposed to the user and used by the front-end to fetch information.
- **Internal API**: Used internally by other services.
- **Registry proxy**: Handles routing of package requests to registry accounts based on policies

## Public Package API

Base path: `/api/v1/svc/packages`

This provides information about packages we have in our registry, allowing users to search, get specific details, or request a re-check of attestation information.

**GET /** - Search packages

- Query params: `q` (optional search term), `ecosystem` (optional filter), `page`, `page_size`
- Returns paginated list of package summaries

**GET /{ecosystem}/{identifier}/{version}** - Get package version details

- Returns full package version info including trust level, source, and tags

**POST /{ecosystem}/{identifier}/{version}/verify** - Trigger re-verification

- Re-checks upstream attestation and OSS rebuild status
- Returns verification results

## Admin API

Base path: `/api/v1/admin`

These are used in the internal dashboard for employees of the company.

**GET /packages** - List watched packages

- Query param: `ecosystem` (required)
- Returns all packages being monitored for the given ecosystem

**POST /packages** - Add package to watch list

- Body: `{ "identifier": "pkg-name", "ecosystem": "npm" }`
- Creates package entry and triggers initial metadata fetch

**GET /packages/{ecosystem}/{identifier}/versions** - List all versions

- Returns version history for a specific package

**POST /packages/{ecosystem}/{identifier}/scan** - Trigger behavioral analysis

- Body (optional): `{ "version": "x.y.z" }` (defaults to latest)
- Creates collection task for be-runner

**GET /packages/{ecosystem}/{identifier}/behavior** - Get deduped behavior tree

- Query param: `version` (required)
- Returns processed behavioral analysis data

**GET /packages/{ecosystem}/{identifier}/behavior/raw** - Get raw behavior tree

- Query param: `version` (required)
- Returns unprocessed behavioral analysis data

**GET /tasks** - List collection tasks

- Query params: `ecosystem`, `page`, `page_size`
- Returns paginated task list with status and artifact info

**GET /tasks/{taskID}/artifact** - Download artifact

- Returns the raw behavioral analysis JSONL file

## Project API

Base path: `/api/v1/projects`

Used by the dashboard for user dependency tracking and security analysis.

Authentication: Bearer API key OR BetterAuth session cookie

**POST /** - Upload project

- Body: `{ "name": "project-name", "file": "<package.json content>" }`
- Parses lockfile, creates/updates project, triggers verification and scans

**GET /** - List user's projects

- Returns all projects belonging to authenticated user

**GET /{projectID}** - Get project details

- Returns project metadata

**GET /{projectID}/dependencies** - List dependencies

- Query param: `type` (optional filter: `direct` or `transitive`)
- Returns all dependencies with version info

**GET /{projectID}/summary** - Get security summary

- Returns aggregated stats: attestation coverage, OSS rebuild status, behavior analysis results

**DELETE /{projectID}** - Delete project

- Removes project and all its dependency links

## Internal API

Base path: `/api/v1/internal`

For inter-service communication only. Not exposed externally.

**POST /packages** - Create package

- Body: `{ "identifier": "pkg", "ecosystem": "npm" }`
- Idempotent package creation

**POST /reproducible-builds** - Register reproducible build

- Body: `{ "ecosystem", "identifier", "version", "tarball": "<base64>" }`
- Tags version as reproducible and uploads artifact to registry

## Registry Proxy

Base path: `/npm`

Proxies npm registry requests to Gitea with smart routing.

**GET /{package}** - Package metadata

- Proxied to appropriate Gitea account

**GET /{package}/-/{package}-{version}.tgz** - Download tarball

- Reproducible builds → spr-registry account
- All others → spr-sandbox account

Authentication: `Authorization: Bearer <api-key>` (required)

Only GET requests are allowed. Non-GET requests return 405 Method Not Allowed.
